Getting started

Echo runs as two containers on one machine: the app you talk to, and a sandbox where the agent's work runs.

What you need

  • Docker with Compose, on Linux or Docker Desktop (macOS or Windows).
  • Permission to run privileged containers. The sandbox needs it to create a jail for each workspace.
  • An API key for at least one model provider, such as Anthropic, OpenAI or Google.

Install

From the Echo folder, create your settings file:

cp .env.example .env

Open .env and set the models people can choose from, and the key for each provider you use:

ECHO_MODELS=anthropic/claude-sonnet-5-5,openai/gpt-5
ANTHROPIC_API_KEY=your key
OPENAI_API_KEY=your key

Then build and start Echo:

docker compose up --build

Choosing models

ECHO_MODELS is a comma separated list of provider/model names, and the first one is the default. Any model that LiteLLM supports can be used as litellm/<model>, for example litellm/ollama/llama3 for a local model. Echo will not start if the list is empty or a name has no provider, and it tells you which setting is wrong.

Keys are read only when Echo starts, so restart it after changing .env:

docker compose restart api

Check it is running

Echo listens only on your own machine, at http://127.0.0.1:8000. Open http://127.0.0.1:8000/api/health and you should see "status": "ok".

If port 8000 is already taken, set another one in .env and start again:

ECHO_PORT=8010

Echo has no sign in yet, which is why it only listens on your own machine. Do not expose it to a network.

If something goes wrong

Every error Echo returns includes a request_id. Search the logs for it to see what happened:

docker compose logs api | grep <request_id>
