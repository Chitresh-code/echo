Using Echo

Your first agent

From signing in to an agent that has learned something, in about as long as it takes to describe the job.

Sign in

Open Echo and choose Sign in with Microsoft. Use your work account, in the organization Echo was set up for. There is no separate Echo password, and your first sign-in creates your Echo account. The first time, Microsoft asks you to agree to share your name and email with Echo.

You stay signed in for 7 days. Sign out from the account menu at the top right.

Add a model key

Your agents think with a model from a provider you pay for, using your own key. Open Credentials in the top bar, pick the provider, give the key a label and paste it. Echo checks the key with the provider before saving it. Model keys covers the providers and what to do if a key is refused.

Create the agent

The Agents page is the first page you see. Choose New agent and give it:

  • A name you will recognize, such as "Release notes".
  • The job it does for you, in a sentence or two, such as "Keep CHANGELOG.md current from merged work".

The agent reads its name and job at the start of every message, so you can change either later with the pencil on the Agents page and it applies from your next message. If you leave the job empty, the agent works it out from what you ask and suggests you write it down.

Give each agent one job. An agent that does one thing builds up skills that fit it, and stays on that job when you come back weeks later.

Find your way around

Creating the agent opens its page, in three panels:

  • Left: tabs for the agent's Files, its Skills (what it has learned) and its Notes (what it remembers from earlier chats).
  • Middle: the editor, where files and skills open.
  • Right: the chat.

On a narrow window the panels stack.

Show it the job

Pick your key and a model under the message box, then ask for the work the way you would brief a colleague. Watch what it does, then correct it: say what to change, and why if that helps. When it saves a correction as a skill, a Learned line appears under its reply.

That is the whole loop. Teaching your agent goes deeper, and Chatting covers the chat panel.

If sign-in fails

When sign-in does not work you land on this page, and the address ends with ?error= and one of these:

wrong_tenant
The account you picked is not in the organization Echo is set up for. Sign in again with your work account.
sign_in_failed
Microsoft did not complete the sign-in, or its answer could not be verified. This also happens when Echo is opened at a different address from the one it was set up with. Try again from the sign-in page. If it keeps failing, ask whoever runs Echo: the reason is in its log.

If you were not given access to Echo, Microsoft says so on its own page instead.
