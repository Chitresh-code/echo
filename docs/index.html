Echo

Echo is a coding and workspace agent you use from the browser. Each workspace is a small project of its own, and an agent works inside it: it runs commands, installs packages, edits files and commits to git. Every workspace runs in its own isolated jail, so the agent can only touch that workspace.

You sign in with your Microsoft work account and bring your own model provider key: Anthropic, OpenAI, Google, or any service with an OpenAI-compatible API. Your workspaces and keys are yours alone; nobody else signed in to Echo can see them.

What you can do today

Echo is in early development. Today you can install it, sign in, add your provider keys, create workspaces, work with their files and git history, and chat with the agent, all through the API. The editor and chat window in the browser are coming next, and these pages describe each one when it is ready to use.
