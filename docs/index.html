User guide

An agent harness
that improves itself.

Echo runs agents in the browser, each with its own workspace, tools and model. Every agent learns from its runs and refines its own skills, instructions and memory, so it gets better with use.

Make your first agent See how it learns

How it learns

Every correction makes the next time better

You do not write instructions up front. You work with the agent the way you would with a new colleague, and it writes down what you taught it.

Safe by design

Each agent works in its own locked room

An agent can run commands, install packages and use the internet, but only inside a workspace of its own. It cannot reach your computer, your network or your other agents.

Get going

Your first workspace in three steps

  1. Sign in and add a key

    Sign in with your Microsoft work account, then add a key from Anthropic, OpenAI, Google or a compatible service.

  2. Ask for the work

    Type it into the box on the home screen. Each message there starts a new workspace, named for you.

  3. Correct it

    Say what to change until it is right. It keeps what it learns.
