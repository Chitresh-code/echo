Echo

Echo is a coding and workspace agent you use from the browser. Each workspace is a small project of its own, and an agent works inside it: it runs commands, installs packages, edits files and commits to git. Every workspace runs in its own isolated jail, so the agent can only touch that workspace.

Echo works with any model provider. You choose which models are offered, and the agent can use any of them.

What you can do today

Echo is in early development. Today you can install it, choose the models it offers, create workspaces, work with their files and git history, and chat with the agent, all through the API. The editor and chat window in the browser are coming next, and these pages describe each one when it is ready to use.
