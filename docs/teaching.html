Using Echo

Teaching your agent

An agent learns from your corrections. It writes each one down as a skill in its workspace, and you can read, change or remove anything it learned.

Corrections become skills

When you correct the agent or show it how you want something done, it saves that as a skill: a file called SKILL.md with the steps, plus any scripts it needs, in a folder of its own under .agent/skills/ in the workspace. It tells you in one line what it learned, and from your next message it uses the skill whenever the task fits.

The Learned line is worked out by comparing the skill files before and after each reply, so it shows what really changed, even if the agent does not mention it. Click a skill name in it to open the file.

Watch for the Learned line. It appears only when a skill really changed. No line means nothing was saved: ask the agent to save the correction as a skill.

See what it knows

The Skills tab in the workspace's files panel lists every skill with its name and when the agent uses it. Click one to open its SKILL.md in the editor, where you can change it like any file. The agent picks up your edit on its next message.

Hover a mark to see what is wrong. You do not have to fix it yourself: the agent is told about both kinds of problem at the start of its next message so it can repair the skill.

To make the agent forget a skill, ask it to remove the skill in the chat. The Learned line shows the removal.

Notes, and making it forget

Besides skills, the agent keeps short notes from each chat: facts and context worth remembering, such as where things are or what you decided. It searches them when they are relevant. The Notes tab lists them, newest first.

Click the bin on a note, then Forget, and the note is deleted for good: the agent no longer remembers it. Keep leaves it as it is.

House rules for the workspace

For conventions about the workspace itself, such as how to run things or where files go, put an AGENTS.md file at the root of the workspace. The agent reads it at the start of every message and keeps it up to date.
