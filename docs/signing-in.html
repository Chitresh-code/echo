Signing in

You sign in to Echo with your Microsoft work account, in the organization Echo was set up for. There is no separate Echo password. Your first sign-in creates your Echo account.

Sign in

Open Echo and choose Sign in with Microsoft. Microsoft asks you to pick your account and, the first time, to agree to share your name and email with Echo. You then land on your agents, signed in. The API reference uses the same session, so every "Try it out" there runs as you.

A session lasts 7 days; after that, sign in again. Sign out in the account menu at the top right ends it straight away. From the API, GET /api/auth/me shows who you are signed in as and POST /api/auth/logout signs you out.

Using your session from curl

Your session is a cookie named echo_session. To use the API from curl, copy its value from your browser's developer tools (Application or Storage, then Cookies, then the Echo address) and send it with every request:

curl -b 'echo_session=the value' http://localhost:8000/api/auth/me

The examples on the other pages use $ECHO for the cookie, so set it once in your shell:

export ECHO='echo_session=the value'

Anyone with this value can act as you until the session ends, so do not paste it anywhere shared. Signing out ends it everywhere.

Without a session, every API call answers 401 with the code not_signed_in.

If sign-in fails

When sign-in does not work you land on this page, and the address ends with ?error= and one of these codes:

  • wrong_tenant: the account you picked is not in the organization Echo is set up for. Sign in again with your work account.
  • sign_in_failed: Microsoft did not complete the sign-in, or its answer could not be verified. This also happens when you opened Echo at a different address from the one it is set up with. If you were not given access to Echo in Entra, Microsoft says so on its own page instead. Try again from the sign-in page; if it keeps failing, whoever runs Echo can find the reason in its log.

Someone removed from the organization or from Echo's access in Entra cannot sign in again, but a session they already have stays valid until it ends, up to 7 days later.
